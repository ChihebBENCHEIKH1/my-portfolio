# Chiheb Bencheikh portfolio

React, TypeScript, Vite and React Three Fiber. The English/German cyberpunk edition includes an automatic interactive 3D city, accessible controls, public profile exports and direct inquiry delivery.

```sh
npm run dev
npm run build:cyberpunk
npm run verify:seo
npm run verify:profile
```

See [publication instructions](docs/deployment.md), [contact contract and measurement](infrastructure/contact/README.md), and [architecture notes](CLAUDE.md). The alternate Art Deco edition remains a local, unapproved design.
